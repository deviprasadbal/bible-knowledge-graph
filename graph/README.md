# The Knowledge Graph

This folder is generated by `pipeline/build_graph.py`. Don't edit it by hand.

| File | What it is |
|---|---|
| `bible_kg.json` | The whole graph as node-link JSON (`nodes`, `edges`). Load it in Python with NetworkX, or in JS with any graph library. |
| `neo4j/nodes.csv`, `neo4j/edges.csv` | Neo4j bulk-import files. They add **31,102 Verse nodes**, plus `MENTIONS`, `DESCRIBES`, `CROSS_REFERENCES` (votes ≥ 10) and `KEY_VERSE` edges. |
| `stats.json` | Node and edge counts by type. |

## Schema

```
(Person)-[:PARENT_OF|SIBLING_OF|MARRIED_TO]->(Person)
(Person)-[:BORN_IN|DIED_IN]->(Place)          (Person)-[:MEMBER_OF]->(Group)
(Person)-[:APPEARS_IN {weight}]->(Book)         (Person)-[:WROTE]->(Book)
(Person|Group)-[:PARTICIPATED_IN]->(Event)      (Event)-[:OCCURRED_AT]->(Place)
(Event)-[:FOLLOWS|PART_OF]->(Event)             (Event)-[:RECORDED_IN]->(Book)
(Place)-[:MENTIONED_IN {weight}]->(Book)        (Place)-[:PART_OF]->(Place)
(Book)-[:ECHOES {weight}]->(Book)               (Creed)-[:CITES {weight}]->(Book)
(Theme)-[:RELATED_TO]->(Theme)                  (Theme)-[:EXEMPLIFIED_BY]->(Person)
(Theme)-[:CONFESSED_IN]->(Creed)                (Theme)-[:TAUGHT_IN]->(Book)
(Book)-[:EXPLORES]->(Theme)
-- Neo4j export only --
(Verse)-[:MENTIONS]->(Person|Place)             (Verse)-[:DESCRIBES]->(Event)
(Verse)-[:CROSS_REFERENCES {weight}]->(Verse)   (Theme)-[:KEY_VERSE]->(Verse)
```

Every node has a stable ID such as `person:abraham_58`, `place:jerusalem_636`, `event:e1`, `book:John`,
`theme:sola-gratia`, `creed:heidelberg_catechism` or `verse:John.3.16`. People who share a name keep separate IDs.

## Loading into Neo4j

```bash
neo4j-admin database import full --nodes=graph/neo4j/nodes.csv --relationships=graph/neo4j/edges.csv bible
```

## Example questions (Cypher)

```cypher
// Who were Abraham's children?
MATCH (:Person {name:'Abraham'})-[:PARENT_OF]->(c) RETURN c.name;

// How is Ruth connected to David? (family links only)
MATCH p = shortestPath((:Person {id:'person:ruth_2450'})-[:PARENT_OF|MARRIED_TO*..6]-(:Person {id:'person:david_994'}))
RETURN [n IN nodes(p) | n.name];

// Which books does the Westminster Confession cite most?
MATCH (:Creed {id:'creed:westminster_confession_of_faith'})-[r:CITES]->(b:Book)
RETURN b.name, r.weight ORDER BY r.weight DESC LIMIT 10;

// Which verses echo John 3:16 most strongly?
MATCH (:Verse {id:'verse:John.3.16'})-[r:CROSS_REFERENCES]-(v) RETURN v.name, r.weight ORDER BY r.weight DESC;
```

The same questions work in Python:

```python
import json, networkx as nx
g = json.load(open('graph/bible_kg.json'))
G = nx.MultiDiGraph()
G.add_nodes_from((n['id'], n) for n in g['nodes'])
G.add_edges_from((e['source'], e['target'], {'type': e['type']}) for e in g['edges'])
print(nx.shortest_path(G.to_undirected(), 'person:ruth_2450', 'person:david_994'))
```
